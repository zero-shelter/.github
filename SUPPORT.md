# Support

Use [Discussions](https://github.com/zero-shelter/discussions/discussions) for usage questions, troubleshooting, ideas, and shared experiences. Follow the community [participation guide](https://github.com/zero-shelter/discussions/blob/main/CONTRIBUTING.md) to choose a category and prepare a useful post.

Use a product repository Issue for reproducible bugs, scoped work, or documentation changes, following that repository's contribution guide. For zero-shelter product contributions, see [CONTRIBUTING.md](https://github.com/zero-shelter/zero-shelter/blob/main/CONTRIBUTING.md).

Do not use public channels for undisclosed vulnerabilities, secrets, or personal information. Follow the applicable repository's `SECURITY.md` and the [organization security policy](https://github.com/zero-shelter/.github/blob/main/SECURITY.md) for private reporting.
